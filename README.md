
# E-Commerce Database Design

This project models a relational database for an e-commerce platform.

## Entities
- Customer
- Order
- Product
- Category
- Address
- OrderItem

## Relationships
- Customers place Orders (1:M)
- Orders contain Products (M:N)
- Products belong to Categories (M:1)
